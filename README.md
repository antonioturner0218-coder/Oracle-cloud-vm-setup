# Oracle-cloud-vm-setup
Steps and instructions for setting up a virtual machine in Oracle Cloud
Created an Oracle Cloud account by signing up with an email and payment information
Logged into Oracle Cloud  and navigated to the "Create a Resource" section
Selected "Compute" and created a virtual machine instance with my chosen (Ubuntu)
Configured the shape (CPU/memory) and network settings, assigning a public IP for access
Generated an SSH key, downloaded it, and launched the VM
After the VM started, I connected via SSG using the key
Updated the system package and installed the tools I needed
